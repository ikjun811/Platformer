# GDD — 프로젝트 Platformer (가칭)

> 상태: **v1.1 확정** (2026-10-20)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2D 횡스크롤 메트로배니아 |
| 컨셉 | 메트로이드 시리즈(슈퍼, 퓨전, 제로 미션, 드레드 등)의 시스템을 계승하고 개선. **게임 감각과 그래픽은 드레드를 기준**으로 한다 |
| 플랫폼 | PC (키보드 전용. 마우스·게임패드 미사용) |
| 아트 | 고해상도 2D 일러스트 (픽셀아트 아님). 애니메이션은 프레임마다 한 장씩 그린 이미지를 이어 재생한다 |
| 1차 목표 | **구역 1개, 플레이 시간 5~10분** 분량 완성 |
| 이후 | 추가 구역은 1차 목표 완성 후 결정 |

### 원작 IP 관련 원칙
- 시스템과 구조는 메트로이드 시리즈를 참고한다.
- 이름, 캐릭터, 스토리, 아트, 사운드는 모두 오리지널로 만든다.
- 시리즈 고유의 설정 요소(X 기생체, SA-X 등)는 따라가지 않는다.

## 2. 세계관

- 무대: 우주 연구 시설. 시설 안에 환경별 구역(정글, 혹한, 화산 등)이 있다.
- 구조: 중앙 허브와 여러 구역이 연결되고, 각 구역은 방 단위로 나뉜다.
- 1차 목표 구역: **정비 구역** — 시설 입구에 있는 기계·배관 테마의 구역
- 주인공, 시설 이름, 스토리 세부 내용: 미정 (10장 참고)

## 3. 플레이어

### 3.1 기본 능력 (처음부터 사용 가능)
| 능력 | 설명 |
|---|---|
| 달리기 | 빠르고 반응이 즉각적인 수평 이동 (드레드 기준) |
| 점프 | 가변 점프(버튼을 누른 시간에 따라 높이 조절), 코요테 타임, 점프 입력 버퍼 |
| 난간 잡기 | 모서리를 잡고 매달린 뒤 기어오른다 |
| 앉기 | 멈춘 상태에서 낮은 자세. 낮은 적을 조준할 때 쓴다 |
| 슬라이드 | 달리는 중에 낮은 자세로 미끄러진다. 높이 2타일 통로를 통과한다 |
| 8방향 빔 | 기본 사격. 8방향으로 조준한다 |
| 차지 빔 | 버튼을 누르고 있으면 충전하고, 놓으면 강한 사격 |
| 카운터 패링 | 적의 돌진·공격에 타이밍을 맞춰 근접 반격한다 (4장) |

### 3.2 획득 능력
| 능력 | 효과 | 얻는 곳 |
|---|---|---|
| 모프볼 | 구르기 형태. 높이 1타일 통로를 통과한다 | 1구역 데이터 룸 |
| 미사일 | 탄약을 쓰는 강한 사격. 미사일 문과 블록을 파괴한다 | 1구역 |
| 이단 점프 | 공중에서 한 번 더 점프 | 1구역 보스 보상 |
| 벽 점프·벽 타기 | 벽에 붙어 미끄러지다가 벽을 차고 점프 | 추후 구역 |
| 대시 | 짧은 순간 빠르게 돌진 | 추후 구역 |
| 밤 | 모프볼 상태에서 설치. 블록을 파괴하고 밤 점프를 한다 | 추후 구역 |
| 빔 강화 | 관통, 확산 등 | 추후 구역 |

### 3.3 조작
키보드 전용이다(마우스·게임패드 미사용). 왼손으로 이동(WASD), 오른손으로 행동(J/K/L)을 맡는다.

| 행동 | 키 |
|---|---|
| 이동·조준 방향 | WASD |
| 점프 | Space |
| 사격 (누르고 있으면 차지) | J |
| 카운터 | K |
| 미사일 전환 (누르는 동안 미사일) | L |
| 제자리 조준 (누르는 동안 멈춰 서서 WASD로 8방향 조준) | Left Shift |
| 앉기 (멈춘 상태) / 슬라이드 (달리는 중) | S |
| 모프볼 | S 두 번 입력 |
| 상호작용 (세이브, 데이터 룸) | W |
| 일시정지 | Esc |
| 맵 | Tab |

**조준 규칙 (8방향)**
- 기본: 바라보는 방향으로 정면 사격
- W: 위. 달리면서 W + 좌우: 위 대각선 (달리기 유지)
- 공중: S는 아래, S + 좌우는 아래 대각선
- Left Shift를 누르는 동안 (제자리 조준)
  - 땅에서는 멈춰 서서 방향 전환과 조준만 한다. W·S·좌우 조합으로 8방향을 조준한다 (땅에서 S만 누르면 앞쪽 아래 대각선)
  - S를 눌러도 앉거나 슬라이드하지 않는다. 앉은 상태에서도 쓸 수 있다
  - 공중에서는 이동을 막지 않는다
- 앉기·슬라이드 중: 정면
- 땅에서 달리면서 아래 대각선은 쏠 수 없다 (S가 슬라이드이므로). 필요하면 Shift로 멈춰서 조준한다

## 4. 전투

### 4.1 체력과 자원
- 에너지: 기본 99. 에너지 탱크 하나당 최대치가 +100 늘어난다 (시리즈 방식).
- 미사일: 획득하면 최대 10발. 확장 아이템 하나당 +5발.
- 회복: 적이 떨어뜨리는 회복 아이템(에너지, 미사일 탄약), 세이브 스테이션에서 완전 회복

### 4.2 카운터 패링
- 적이 공격하기 직전에 신호(빛나기 등)를 보낸다. 이때 카운터를 입력하면 성공한다.
- 성공하면 적이 경직되고, 이어지는 조준 사격이 큰 피해를 준다. 적은 추가로 아이템을 떨어뜨린다.
- 실패하면 짧은 후딜레이가 생긴다 (남발 방지).
- 판정 시간: 0.2초 (초기값, 테스트하며 조정)

### 4.3 피격
- 피격되면 넉백되고 1초 동안 무적이 된다 (스프라이트 깜빡임).
- 가시·용암 같은 환경 피해는 일정량을 깎고, 마지막으로 밟은 안전한 발판으로 되돌린다.

### 4.4 전투 범위
- **포함 (기본 전투)**: 8방향 빔, 차지 빔, 미사일, 카운터(성공 → 적 경직 → 추가 피해), 피격·넉백·무적
- **제외 (특수 연출, 10장에서 추후 검토)**: 카운터 성공 슬로모션·확대 연출, 근접 마무리(처형) 연출, 추격자 구간, 보스 연출 컷, 플래시 시프트, 스피드 부스터, 섀인스파크
- 차지 빔: J를 누르는 순간 일반 빔을 쏘고 충전을 시작한다. 0.9초 이상 누르고 있다가 떼면 차지 빔(크고 빠르고 사거리가 긴 빔)을 쏜다. 다 차기 전에 떼면 충전이 사라진다 (수치는 `PlayerCombatSettings`)
- 조준은 8방향이다. Shift는 드레드식 제자리 조준으로 쓴다 (360도 자유 조준은 키보드 전용 조작에 맞지 않아 제외). 규칙은 3.3 참고

### 4.5 적 설계 원칙
- 적 하나에 역할 하나: 지상 순찰, 비행, 벽 부착, 돌진(카운터 연습용) 등
- 1구역 적: 3~4종 (지상 순찰형, 비행형, 돌진형, 고정 포탑형)
- 1구역 보스 1마리: 카운터와 차지 빔을 활용하는 패턴

## 5. 월드 구조

### 5.1 방(Room) 단위 맵
- 맵은 여러 방으로 나뉘고, 방은 문으로 연결된다.
- 카메라는 방 경계 안에서만 움직인다.
- 방 사이를 이동할 때 짧은 화면 전환 효과를 넣는다.
- 화면 크기: 가로 20타일 x 세로 11.25타일 (16:9)
- 방 크기 기준: 1화면짜리 방 = **20x12타일**. 세로로 넘치는 0.75타일만큼은 카메라가 살짝 스크롤한다. 큰 방은 이 크기의 배수로 만든다.

### 5.2 문
| 종류 | 여는 방법 |
|---|---|
| 일반 문 | 아무 사격 |
| 미사일 문 | 미사일 사격 |
| 보안 레벨 문 (레벨 1, 2, …) | 보안 룸에서 해당 레벨을 해제 |
| 보스 문 | 보스를 처치하면 열림 |

### 5.3 특수 방과 오브젝트
- **세이브 스테이션**: 저장하고 완전 회복한다.
- **데이터 룸**: 능력을 다운로드한다.
- **보안 룸**: 보안 레벨을 해제한다.
- **파괴 블록**: 빔 블록, 미사일 블록 (밤 블록은 추후 구역). 숨겨진 블록은 공격해야 모습이 드러난다.
- **수집 아이템**: 에너지 탱크, 미사일 확장

### 5.4 능력 게이트
어떤 능력으로 어디가 열리는지 정리한 표입니다. 레벨 디자인의 기준이 됩니다.

| 능력 | 열리는 곳 |
|---|---|
| 슬라이드 (기본 능력) | 높이 2타일 통로 (선 키 2.25타일이라 서서는 못 들어가고, 앉은 자세로는 이동할 수 없으므로 슬라이드로만 통과) |
| 모프볼 | 높이 1타일 통로 |
| 미사일 | 미사일 문, 미사일 블록 |
| 이단 점프 | 일반 점프로는 닿지 않는 높은 발판과 넓은 낭떠러지 |
| 보안 레벨 | 같은 레벨의 문 |

**높이 기준** (현재 이동 수치 기준. 수치를 바꾸면 다시 계산한다)

| 이동 방법 | 오를 수 있는 높이 |
|---|---|
| 점프 | 약 3.5타일 |
| 점프 + 난간 잡기 | 약 5.5타일 |
| 이단 점프로만 가야 하는 곳 | **6타일 이상** 높게 만든다 |

## 6. 진행 구조

- **목표 안내**: 다음 목표를 지도에 표시한다. 단, 정해진 경로만 강제하지는 않는다.
- **자유도**: 구역을 고르는 순서에 선택권을 준다(추후 구역부터). 순서 파괴를 허용하고 보상한다.
- **저장과 죽음**
  - 세이브 스테이션에서 수동으로 저장한다.
  - 일반 사망: 마지막 세이브 스테이션에서 재시작한다.
  - 보스전 사망: 보스 방 입구에서 바로 재시작할지 선택할 수 있다.
- **수집률**: 아이템 수집률(%)을 일시정지 화면과 엔딩에 표시한다.

### 6.1 1구역 흐름 (5~10분)
1. **시작 지점**: 이동, 점프, 난간 잡기 튜토리얼. 손이 닿지 않는 높은 발판이 보인다 (이단 점프 복선)
2. **첫 전투**: 빔, 차지 빔, 카운터를 배운다 (돌진형 적)
3. **세이브 스테이션**
4. **데이터 룸**: 모프볼 획득 → 좁은 통로를 지나간다
5. **보안 룸**: 보안 레벨 1 해제 → 잠겨 있던 문을 통과한다
6. **미사일 획득** → 미사일 문으로 보스 구역에 진입한다
7. **세이브 스테이션** (보스 앞)
8. **보스전** → 보상으로 이단 점프 획득
9. **이단 점프로 되돌아가기** → 1번에서 본 높은 발판을 넘어 엘리베이터에 도착 (다음 구역 입구, 1차 목표의 끝)
- 숨겨진 아이템: 에너지 탱크 1개, 미사일 확장 2개
  - 미사일 블록 뒤, 모프볼 통로 안쪽, 이단 점프로만 닿는 곳에 하나씩 배치해서 되돌아가 탐험하면 보상을 준다
- 예상 규모: 방 12~15개

## 7. 시리즈 대비 개선 포인트

| 시리즈의 아쉬운 점 | 개선 |
|---|---|
| 보스전에서 죽으면 먼 세이브 지점부터 다시 와야 함 | 보스 방 입구에서 바로 재시작 |
| 진행이 선형적인 작품이 있음 (퓨전 등) | 목표 안내는 유지하되 구역 선택과 순서 파괴를 허용 |
| 숨겨진 블록을 찾기 너무 어려움 | 미세한 시각 힌트를 넣고, 지도에 미획득 아이템이 있는 방을 표시 |
| 조작감이 작품마다 다름 | 코요테 타임과 입력 버퍼 같은 현대적인 조작 보정을 기본 탑재 |

## 8. 기술 사양

- Unity 6000.3.26f1, URP 2D, 새 Input System
- **게임 단위**: 1타일 = 1유닛. 충돌체와 이동 수치는 유닛 기준이다
- **스프라이트**: PPU 128 (1타일 = 128px), Filter Mode = Bilinear, 압축 사용
- **카메라**: 일반 Orthographic 카메라 (Size 5.625 = 세로 11.25타일). (Pixel Perfect Camera는 아트 파이프라인 전환 때 제거함)
- **이동 수치 (드레드 기준 초기값)**: 최고 속도 9.5, 지상 가속·감속 150. 점프 높이는 3.5타일 유지 (5.4장 높이 기준과 연결). 슬라이드: 충돌체 높이 1.25타일, 속도 13, 0.4초, 시작 최소 속도 6
- **레이어**: Ground, OneWay, Player, Enemy, PlayerProjectile, EnemyProjectile, Interactable, Room
- **태그**: Player 외에는 쓰지 않는다. 판별은 컴포넌트와 레이어로 한다.
- **밸런스 데이터**: ScriptableObject (`Assets/_Project/Data/`)
- **저장**: JSON 파일 (`Application.persistentDataPath`)
- **아트 제작**
  - 캐릭터: AI 이미지 도구(Gemini)로 프레임마다 한 장씩 만든다 (부위 분리 애니메이션은 시간과 비용 때문에 쓰지 않는다). 명령서는 `Docs/ArtSamples/GeminiSpec.md`
  - 처리: `python Tools/ArtPipeline/process_sprites.py`가 Gemini 원본(`Docs/ArtSamples/Gemini/make/`)의 배경을 지우고 크기·위치를 맞춰 `Assets/_Project/Art/Characters/`에 가로 시트로 저장한다
  - 시트 규격: 칸 384x384 (기어오르기만 512x768), 서 있는 키 288px, 피벗 = 서 있을 때 충돌체 바닥 중앙 (칸 아래쪽 x 192)
  - 재생: `PlayerAnimator`가 시트를 런타임에 잘라 상태별로 재생한다 (Animator Controller 미사용)
  - 타일, 배경: Asset Store 에셋을 가공해서 쓴다 (출처는 `Docs/Credits.md`). `python Tools/ArtPipeline/make_environment.py`가 `Assets/_Project/Art/Environment/`에 만든다
    - 지형: 바탕 타일 4장(금속판 무늬가 이어지도록 월드 좌표 짝·홀로 선택) + 테두리 덧칠 타일 15장(노출된 면 조합, 별도 타일맵 `GroundEdge`)
    - 배경: 패럴랙스 4겹 — 우주 성운(0.92) → 별 두 겹(0.9, 0.85) → 창문 뚫린 시설 벽(0.3). 괄호는 카메라를 따라가는 비율(`ParallaxLayer`)
    - 소품: 추후
  - 프레임 사이 디자인 일관성은 기준 이미지 한 장을 정해 모든 생성의 참조로 쓰는 방식으로 맞춘다
- **입력**: 기존 `InputSystem_Actions`를 3.3의 조작에 맞게 수정한다 (M0)
