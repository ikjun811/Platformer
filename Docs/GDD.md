## 2. 세계관 (초안)

- 무대: 외계 생물에 점령된 우주 기지. 복도, 관제실, 창고, 수직 샤프트로 이루어진다.
- 주인공: 기지에 투입된 해병 1명.
- 적: 기지를 점령한 외계 생물과 감염된 기지 병사.
- 주인공, 기지 이름, 스토리 세부 내용: 미정 (10장)

## 3. 플레이어

### 3.1 동작
| 동작 | 설명 |
|---|---|
| 달리기 | 좌우 이동. 바라보는 방향이 곧 사격 방향이다 |
| 점프 | 가변 점프, 코요테 타임, 점프 입력 버퍼 (기존 구현 유지) |
| 발판 내려가기 | 얇은 발판(OneWay) 위에서 S + Space로 아래로 떨어진다 (그 발판을 0.25초 무시). 단단한 바닥에서는 평소처럼 점프한다 |
| 낮은 턱 넘기 | 계단 같은 낮은 단차(0.15타일 이하, 계단 한 칸 = 8px)는 점프 없이 걸어서 오르내린다. 단단한 지형(Ground)만 해당 |
| 사격 | **좌우 수평으로만** 쏜다. 무기 모듈과 과열은 4장 |
| 페이즈 대시 | 짧은 거리를 순간 이동하듯 돌진한다. 대시 중에는 무적이고 적을 통과한다. **3번까지 연속으로** 쓸 수 있다 (4.4) |
| 카운터 | 적이 공격 전에 신호를 보낼 때 맞춰 반격한다 (4.5) |

- 이전 기획의 앉기, 난간 잡기, 슬라이드, 8방향 조준은 **제거**한다 (애니메이션 없음, 새 전투에서 쓰지 않음).

### 3.2 조작
왼손으로 이동(WASD)과 대시 외 보조, 오른손으로 전투(J/K/L)를 맡는다.

| 행동 | 키 |
|---|---|
| 좌우 이동 | A / D |
| 점프 | Space |
| 발판 내려가기 | S + Space |
| 사격 (누르고 있으면 차지) | J |
| 카운터 | K |
| 페이즈 대시 | L |
| 무기 모듈 교체 (순환) | Q |
| 일시정지 | Esc |

- 이전 액션 중 `AimLock`(Shift), `Missile`(L), `Map`(Tab)은 삭제하고 `Dash`(L), `SwapWeapon`(Q)을 추가한다.

### 3.3 애니메이션 (에셋에 없는 동작은 기존 프레임을 재활용)
| 상태 | 사용 프레임 |
|---|---|
| 서기 | `marine_stand_1~2` |
| 달리기 | `marine_run_1~6` |
| 사격 | `marine_shoot_1~2` (서기·달리기 중 사격 시 덮어씀) |
| 점프·낙하 | `marine_run_3` 고정 |
| 대시 | `marine_run_3` 고정 + 잔상(반투명 복제)을 남긴다 |
| 피격 | 현재 프레임을 흰색으로 깜빡인다 |
| 사망 | `marine_die_1~5` |

- 모든 캐릭터(플레이어 포함)에 몸 색 계열의 **1px 외곽선**을 넣는다. 어두운 샤프트 배경에서도 형태가 보이게 하기 위해서다

## 4. 전투

### 4.1 체력
- 플레이어 체력: 100 (초기값)
- 피격: 넉백 + 1초 무적 (흰색 깜빡임). 기존 `PlayerHurt` 유지
- 회복: 카운터 처치로 나오는 체력 조각 (4.5), 방을 클리어하면 일부 회복 (수치는 테스트하며 정한다)

### 4.2 과열 게이지
탄약 대신 과열로 사격을 제한한다.
- 사격할 때마다 열이 오른다. 잠시 쏘지 않으면 식는다.
- 게이지가 꽉 차면 **과열**: 일정 시간 동안 사격할 수 없다.
- **과열 배출 (P1)**: 과열되면 게이지 위에 타이밍 표시가 움직인다. 표시가 성공 구간에 있을 때 J를 누르면
  - 열이 즉시 0이 되고, 주변 적을 밀쳐내는 충격파가 나간다.
  - 실패하면 과열 시간이 늘어나고, 그 과열 동안은 다시 시도할 수 없다.
- 과열 시간이 끝나면 열이 0이 된다. 과열 중에는 충전도 끊긴다.
- 초기값: 최대 100, 일반 탄 +10, 차지 샷 +35, 마지막 사격 0.35초 뒤부터 초당 45씩 식음, 과열 1.5초, 성공 구간 40~60%, 실패 시 +0.75초, 충격파 반지름 1.5타일 (적을 밀어내고 0.5초 경직)
- 수치는 `PlayerCombatSettings`. 게이지는 HUD(N5) 전까지 플레이어 머리 위 임시 막대로 표시한다 (`PlayerHeatGauge`)

### 4.3 무기 모듈
블래스터 하나에 모듈을 바꿔 끼운다. Q로 순환한다. 탄 스프라이트(`blasterfire`)의 길이와 색으로 구분한다.

| 모듈 | 특징 | 열 | 초기값 (피해 / 연사 간격 / 열 / 속도 / 사거리) |
|---|---|---|---|
| W1 연사 (기본) | 빠른 연사, 보통 피해 | 보통 | 10 / 0.12초 / 10 / 14 / 9타일 |
| W2 관통탄 | 느린 연사, 높은 피해. 일렬로 늘어선 적을 꿰뚫는다 (벽에서 멈춤, 적마다 한 번씩 피해) | 높음 | 25 / 0.35초 / 22 / 18 / 10타일 |
| W4 산탄 | 위아래 24도로 퍼지는 3발, 짧은 사거리. 높이가 다른 적을 동시에 맞힌다 | 높음 | 7×3 / 0.3초 / 20 / 12 / 5타일 |

- 수치는 모듈마다 `WeaponModule` 에셋(`Data/V2/Weapons/`), 쓸 수 있는 목록은 `WeaponLoadout` 에셋. 열은 탄 수와 상관없이 한 번 쏠 때 한 번 오른다
- 사격은 J를 누를 때마다 한 번 (단발). 현재 모듈은 HUD(N5) 전까지 임시 게이지 왼쪽 색 칸으로 표시한다

- **차지 샷**: J를 누르면 일반 탄을 쏘고 충전을 시작한다. 충분히 누른 뒤 떼면 강한 탄을 쏜다. 모든 모듈에 공통이고, 열을 많이 쓴다.
- 모듈 획득 방식: 1차 목표에서는 **처음부터 3종 모두** 쓸 수 있다. 진행하며 하나씩 얻는 방식으로 바꿀 수 있으므로, 사용 가능 모듈 목록을 데이터로 분리해 둔다

### 4.4 페이즈 대시
- 누르면 바라보는 방향(이동 키를 누르고 있으면 그 방향)으로 짧은 거리를 매우 빠르게 이동한다.
- 대시 중에는 **무적**이고 적과 적의 탄을 통과한다. 벽은 통과하지 못한다.
- **연속 3회**: 대시 사이 간격이 짧으면 최대 3번까지 이어서 쓸 수 있다. 3번을 다 쓰거나 연결 시간이 지나면 재사용 대기 시간이 시작되고, 끝나면 3회가 모두 충전된다.
- 땅과 공중 모두 쓸 수 있다. 공중에서는 대시하는 동안 중력을 받지 않는다.
- 초기값 (테스트하며 조정): 거리 1.95타일, 시간 0.13초 (처음 1.5타일·0.1초에서 러너 몸길이에 맞춰 1.3배로 늘림, 속도는 같음), 연결 시간 0.4초, 재사용 대기 1.2초
- 무적은 피격 무적과 따로 둔 **회피 무적**(`Health.SetEvading`)이라 깜빡이지 않는다. 대시가 끝난 뒤 0.05초까지 유지된다
- 적 통과는 대시 중에만 플레이어 몸에서 Enemy 레이어를 제외하는 방식(`Rigidbody2D.excludeLayers`)이다
- 대시가 끝날 때 적과 겹쳐 있으면 **빠져나올 때까지 이어서 간다** (최대 1.5타일 추가, 그동안 무적 유지). 큰 적도 한 번에 통과한다. 대시 사이 무적을 잇는 방식은 3연속 동안 계속 무적이 되어 너무 강하므로 쓰지 않았다
- 수치는 `PlayerDashSettings` (`Data/V2/PlayerDashSettings.asset`)

### 4.5 카운터
- 근접형 적은 공격하기 직전에 **신호**를 보낸다. 몸이 빛나고 예비 동작(외계 생물 `bite_1~2`)을 한다.
- 신호가 뜬 뒤 판정 시간 안에 K를 누르면 성공한다. 적이 튕겨나가며 경직된다.
- 실패하면(신호가 없을 때 누르면) 짧은 후딜레이가 생긴다.
- **카운터 처치 (P2)**: 경직된 적을 가까이에서 쏘면 즉사한다. 체력 조각이 떨어지고 열이 크게 내려간다.
- 판정 시간 0.2초, 경직 1.5초, 실패 후딜레이 0.4초 (초기값)
- 판정 범위: 바라보는 쪽 몸 앞 1타일, 높이 1타일. 범위 안에서 신호 중인 적은 모두 경직된다. 뒤쪽 적은 카운터되지 않는다
- 성공하면 0.25초 동안 피해를 받지 않는다 (옆의 다른 적 공격 방지). 실패 후딜레이 동안은 사격도 못 한다
- 경직된 적은 실루엣이 느리게 반투명으로 깜빡인다 (처치 가능 표시)
- 경직 중 밀려나는 가로 속도는 `EnemySettings.knockbackDeceleration`(초기 2타일/초²)으로 줄어든다. 카운터 경직은 약 2.2타일 밀려난다 (2026-10-27 "너무 멀다" 피드백으로 절반으로 줄임)
- 카운터 처치: 경직된 적이 몸 앞 1.6타일 안에 있을 때 어떤 탄(차지 샷 포함)이든 쏘는 순간 즉사. 체력 조각(20 회복, 10초 뒤 사라짐)이 떨어지고 열이 50 내려간다
- 수치는 `PlayerCounterSettings`. 카운터를 받는 적은 `ICounterable`을 구현한다 (러너: 신호 중)

### 4.6 적
외계 생물과 해병 스프라이트를 색과 크기로 변형해 역할을 나눈다. 크기는 픽셀이 깨지지 않도록 **정수배**만 쓴다 (예외: 브루트 1.5배).

| 적 | 원본 변형 | 행동 | 카운터 |
|---|---|---|---|
| E1 러너 | 외계 생물 (기본) | 플레이어를 향해 달려와 문다 | 가능 |
| E2 브루트 | 외계 생물 1.5배 크기, 붉은 색조 | 느리고 단단하다. 정면 사격 피해가 줄어든다. 물기에 넉백이 크다 | 가능 (주요 공략법) |
| E3 천장 기생체 | 외계 생물 상하 반전 | 천장을 기어 다니다 플레이어 머리 위로 떨어진다 | 불가 |
| E4 폭발체 | 외계 생물, 발광 색조 | 가까이 오면 잠시 부풀었다가 자폭한다. 사격으로 죽이면 그 자리에서 터져 주변 적까지 피해를 준다 | 불가 |
| E5 감염 병사 | 해병, 녹색 색조 | 멈춰서 수평 사격. 플레이어와 같은 층에 있을 때만 쏜다 | 불가 |

- 사망: 외계 생물 `alien_die_1~5`, 병사 `marine_die_1~5`. 죽으면 충돌이 꺼지고 사망 동작 뒤 사라진다 (`EnemySettings.deathDuration`, 기본 0.5초). 혈흔(`blood_*`)은 N8 연출
- 피격 번쩍임과 공격 신호는 흰 실루엣 시트를 몸 그림 위에 겹쳐 보여준다 (어두운 외계 생물은 색 곱하기로 번쩍임이 보이지 않기 때문)

**E1 러너 동작** (`EnemyRunner`, 수치 `EnemyRunnerSettings`)
- 대기 → 플레이어가 같은 층(높이 차 1.5타일 안), 가로 6타일 안, 사이에 벽 없음 → 추격 (속도 3.2, 플레이어보다 느림)
- 몸 앞면과 플레이어 사이가 0.5타일 안이면 **웅크림 0.5초**. 마지막 **0.2초는 하얗게 깜빡이는 신호 = 카운터 판정 시간**
- 튀어 물기: 0.15초 동안 속도 6으로 튀어 나가며 앞쪽 판정에 닿으면 15 피해 (한 번)
- 쉬기 0.6초 뒤 다시 추격. 낭떠러지·벽 앞에서는 멈춘다 (자기 층을 벗어나지 않음)
- 경직(충격파, 카운터)되면 공격을 끊고 경직이 끝난 뒤 쉬기부터 다시 시작
- 체력 30, 몸 접촉 피해 5 (물기가 주 공격)

**E2 브루트 동작** (러너와 같은 `EnemyRunner`, 수치 `Data/V2/EnemyBruteSettings`, 그림 1.5배)
- 크기: 2배는 대시(1.95타일)로 통과하지 못해 **1.5배**로 줄였다 (2026-10-27 사용자 요청). 정수배 원칙의 예외로, 픽셀이 고르지 않게 보일 수 있다. 충돌체 1.35 x 1.05타일
- 체력 120, 추격 속도 1.8, 웅크림 0.8초 (신호 0.3초 = 러너보다 카운터하기 쉬움), 물기 25 피해 + **넉백 2배**, 쉬기 1초
- **정면 피해 70% 감소**: 브루트가 보는 쪽에서 맞은 탄은 피해가 0.3배 (최소 1). 뒤에서 맞히거나(대시로 통과 후) 카운터 처치로 잡는다. 카운터 처치는 감소를 무시하고 즉사
- 무거워서 충격파·카운터에 밀려나는 거리가 절반 (`knockbackScale` 0.5)
- 공통 장치: 피해 감소는 `IDamageModifier`(Enemy가 구현), 넉백 배율은 `DamageInfo.KnockbackScale`

**E5 감염 병사 동작** (`EnemyShooter`, 수치 `Data/V2/EnemyInfectedSettings`, 녹색 해병 그림, 몸 크기는 플레이어와 같음)
- 같은 층(높이 차 1타일 안), 가로 8타일 안, 사이에 벽 없음 → 걸어서 접근 (속도 1.5). 6타일 안이면 멈춘다
- 겨눔 0.5초(사격 자세로 예고) → 0.2초 간격으로 3발 → 쉬기 1.5초 → 계속 보이면 다시 겨눔
- 탄: 피해 10, 속도 8 (플레이어 탄 14보다 느려 보고 피할 수 있음), 사거리 9타일. EnemyProjectile 레이어, 지형과 플레이어에만 맞는다
- 다른 층으로 피하면 쏘지 않는다 (층 바꾸기 = 회피, GDD 5.3). 대시 중 무적으로 탄을 통과할 수 있다
- 체력 40, 몸 접촉 피해 5. 카운터 불가, 충격파로는 경직된다
- 색 변형: 미리 만든 색 변형 시트를 쓴다 (팔레트 색을 하나씩 바꿈, 2026-10-27 확정). 공격 신호와 피격 깜빡임은 흰 실루엣 시트를 겹쳐 표시한다

## 5. 방 구조

### 5.1 방 유형
| 유형 | 내용 | 상태 |
|---|---|---|
| **R1 소탕** | 들어오면 문이 잠긴다. 정해진 웨이브를 모두 처치하면 열린다 | **1차 목표의 중심** |
| R2 방어 | 콘솔이 작동하는 동안 지킨다 | 추후 추가 |
| R3 탈출 | 제한 시간 안에 반대편 문까지 간다 | 추후 추가 |
| R4 보스 | 거대 외계 생물(3배 크기) 등 | 추후 추가 |
| 통로 | 전투 없이 다음 방으로 잇는 복도 | 1차 목표 포함 |

### 5.2 소탕 방(R1) 규칙
- 웨이브 구성(적 종류, 수, 출현 위치, 출현 시점)은 방마다 ScriptableObject 데이터로 정한다.
- 적은 방의 **문**과 **화면 밖 가장자리**에서 등장한다.
- 다음 웨이브는 남은 적이 일정 수 이하가 되면 시작한다.
- 마지막 웨이브를 정리하면 문이 열리고 방 평가(6장)를 보여준다.

**구현 (N4)**
- `Room`: 플레이어가 시작 영역(왼쪽 문에서 2.5타일 안쪽부터 방 끝까지)에 들어오면 문을 모두 닫고 웨이브를 진행한다. 마지막 웨이브는 전부 처치해야 끝나고, 끝나면 문이 열린다
- `RoomWaveData` (SO, `Data/V2/Rooms/`): 웨이브마다 (적 프리팹, 출현 지점 번호, 웨이브 시작 후 지연 시간) 목록과 "남은 적이 이 수 이하면 다음 웨이브"
- `RoomDoor`: 닫히면 지형(Ground) 충돌체와 **방 벽과 같은 블록 그림**을 켜서 출입구를 메운다. 플레이어·적·탄 모두 막힌다. 문 그림은 닫힌 것처럼 보이지 않아 블록 차단으로 바꿨다 (2026-10-27 사용자 요청)
- 적 프리팹: `Prefabs/Enemies/` (Runner, Brute, Infected). 빌더가 만든다
- 출현 지점: 지금은 방 안의 정해진 자리(발 위치). 문·화면 밖 가장자리 출현은 출현 지점을 그 위치에 두는 것으로 처리하고, 등장 연출은 N8
- 방 단위 재시작: 방이 시작되면 플레이어의 부활 위치가 그 방 입구 바깥(통로)으로 바뀐다. 소탕 중 죽으면 웨이브 중단, 생성한 적 제거, 출입구 열림으로 방이 처음 상태가 되고, 플레이어는 입구에서 체력·열을 채워 다시 시작한다. 다시 들어가면 첫 웨이브부터. 부활 직후에는 마지막 피격의 무적(1초)이 남아 있어 날아오던 적 탄에 맞지 않는다 (`Room`, `IRespawnable` ← `PlayerHurt`)
- 테스트 방 웨이브 (초기값): ① 러너 2 → ② 감염 병사 1 + 러너 2 (1마리 남으면 다음) → ③ 브루트 1 + 러너 2

### 5.3 방 크기와 지형
- 1화면 = 가로 10타일 x 세로 5.625타일. 1화면짜리 방 = **10x6타일** (복도 단면 6행). 세로로 넘치는 0.375타일은 카메라가 살짝 스크롤한다.
- 소탕 방 기준: 가로 2~3화면(20~30타일), 세로 1~2층(6 또는 12타일).
- 층 구성: 바닥, 얇은 발판(OneWay), 계단 지형으로 높이를 나눈다. 수평 사격만 있으므로 **층을 바꾸는 것이 곧 회피**다.
- 높이 기준: 점프 한 번으로 한 층(약 2타일)을 오를 수 있게 한다 (수치는 8장 이동 재조정 때 확정).

## 8. 기술 사양

- Unity 6000.3.26f1, URP 2D, 새 Input System
- **게임 단위**: 1타일 = 1유닛 = 64px
- **스프라이트**: PPU 64, Filter Mode = Point, 압축 없음, 피벗 = 발 중앙 (캐릭터) / 왼쪽 아래 (타일)
- **카메라**: Pixel Perfect Camera, 기준 해상도 **640x360** (가로 10타일 x 세로 5.625타일). 720p 2배, 1080p 3배, 1440p 4배, 4K 6배로 정수 확대된다. Crop Frame = Windowbox (정수배가 아닌 창에서는 검은 테두리로 보이는 범위를 유지), Grid Snapping = Pixel Snapping. 메뉴 `Tools/Platformer/Setup/Pixel Perfect Camera (Current Scene)`
- **캐릭터 크기 참고**: 해병 키 약 41px(0.64타일), 외계 생물 몸길이 약 110px(1.7타일)
- **이동 수치**: 이전 수치(키 2.25타일 기준)는 쓰지 않는다. 새 수치 SO는 `Assets/_Project/Data/V2/`에 있다. N1 조정값 (2026-10-27): 최고 속도 4.5, 지상 가감속 60, 점프 2.2타일 (최고점 0.45초, 낙하 중력 1.5배), 최대 낙하 12. 대시 1.95타일. 달리기·대시 거리는 사용자 확인 완료, 점프는 "높이 적당·속도 빠름" 피드백으로 체공 시간을 늘림
- **플레이어 충돌체**: 0.3125 x 0.625타일 (20 x 40px)
- **테스트 씬**: `Assets/_Project/Scenes/TestArena.unity`. 메뉴 `Tools/Platformer/Build Test Arena`가 42x12타일 구역을 만든다: 왼쪽 통로(시작 위치) → 문 → 30x12타일 2층 소탕 방(바닥 + 얇은 발판 윗면 4·6·8 + 계단, 출현 지점 4곳) → 문 → 오른쪽 통로

- **소팅 레이어**: Default → Background → Tiles → Props → Characters → Projectiles → FX → UI (뒤일수록 앞에 그려짐). 메뉴 `Tools/Platformer/Setup/Sorting Layers`

- **밸런스 데이터**: ScriptableObject (`Assets/_Project/Data/`)
