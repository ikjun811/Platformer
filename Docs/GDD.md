## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2D 횡스크롤 슈팅 플랫포머 |

| 핵심 재미 | 적이 오는 방향을 읽고, 쏘고, 과열을 관리하고, 위험한 순간을 대시와 카운터로 뒤집는다 |

## 2. 세계관 (초안)

- 무대: 외계 생물에 점령된 우주 기지. 복도, 관제실, 창고, 수직 샤프트로 이루어진다.
- 주인공: 기지에 투입된 해병 1명.
- 적: 기지를 점령한 외계 생물과 감염된 기지 병사.
- 주인공, 기지 이름, 스토리 세부 내용: 미정 (10장)

## 3. 플레이어

### 3.1 동작
| 동작 | 설명 |
|---|---|
| 달리기 | 좌우 이동. 바라보는 방향이 곧 사격 방향이다 |
| 점프 | 가변 점프, 코요테 타임, 점프 입력 버퍼 (기존 구현 유지) |
| 발판 내려가기 | 얇은 발판(OneWay) 위에서 S + Space로 아래로 떨어진다 (그 발판을 0.25초 무시). 단단한 바닥에서는 평소처럼 점프한다 |
| 낮은 턱 넘기 | 계단 같은 낮은 단차(0.15타일 이하, 계단 한 칸 = 8px)는 점프 없이 걸어서 오르내린다. 단단한 지형(Ground)만 해당 |
| 사격 | **좌우 수평으로만** 쏜다. 무기 모듈과 과열은 4장 |
| 페이즈 대시 | 짧은 거리를 순간 이동하듯 돌진한다. 대시 중에는 무적이고 적을 통과한다. **3번까지 연속으로** 쓸 수 있다 (4.4) |
| 카운터 | 적이 공격 전에 신호를 보낼 때 맞춰 반격한다 (4.5) |

- 이전 기획의 앉기, 난간 잡기, 슬라이드, 8방향 조준은 **제거**한다 (애니메이션 없음, 새 전투에서 쓰지 않음).

### 3.2 조작
왼손으로 이동(WASD)과 대시 외 보조, 오른손으로 전투(J/K/L)를 맡는다.

| 행동 | 키 |
|---|---|
| 좌우 이동 | A / D |
| 점프 | Space |
| 발판 내려가기 | S + Space |
| 사격 (누르고 있으면 차지) | J |
| 카운터 | K |
| 페이즈 대시 | L |
| 무기 모듈 교체 (순환) | Q |
| 일시정지 | Esc |

- 이전 액션 중 `AimLock`(Shift), `Missile`(L), `Map`(Tab)은 삭제하고 `Dash`(L), `SwapWeapon`(Q)을 추가한다.

### 3.3 애니메이션 (에셋에 없는 동작은 기존 프레임을 재활용)
| 상태 | 사용 프레임 |
|---|---|
| 서기 | `marine_stand_1~2` |
| 달리기 | `marine_run_1~6` |
| 사격 | `marine_shoot_1~2` (서기·달리기 중 사격 시 덮어씀) |
| 점프·낙하 | `marine_run_3` 고정 |
| 대시 | `marine_run_3` 고정 + 잔상(반투명 복제)을 남긴다 |
| 피격 | 현재 프레임을 흰색으로 깜빡인다 |
| 사망 | `marine_die_1~5` |

- 모든 캐릭터(플레이어 포함)에 몸 색 계열의 **1px 외곽선**을 넣는다. 어두운 샤프트 배경에서도 형태가 보이게 하기 위해서다

## 4. 전투

### 4.1 체력
- 플레이어 체력: 100 (초기값)
- 피격: 넉백 + 1초 무적 (흰색 깜빡임). 기존 `PlayerHurt` 유지
- 회복: 카운터 처치로 나오는 체력 조각 (4.5), 방을 클리어하면 일부 회복 (수치는 테스트하며 정한다)

### 4.2 과열 게이지
탄약 대신 과열로 사격을 제한한다.
- 사격할 때마다 열이 오른다. 잠시 쏘지 않으면 식는다.
- 게이지가 꽉 차면 **과열**: 일정 시간 동안 사격할 수 없다.
- **과열 배출 (P1)**: 과열되면 게이지 위에 타이밍 표시가 움직인다. 표시가 성공 구간에 있을 때 J를 누르면
  - 열이 즉시 0이 되고, 주변 적을 밀쳐내는 충격파가 나간다.
  - 실패하면 과열 시간이 늘어난다.
- 수치(최대 열, 발당 열, 냉각 속도, 과열 시간, 성공 구간)는 `PlayerCombatSettings`

### 4.3 무기 모듈
블래스터 하나에 모듈을 바꿔 끼운다. Q로 순환한다. 탄 스프라이트(`blasterfire`)의 길이와 색으로 구분한다.

| 모듈 | 특징 | 열 |
|---|---|---|
| W1 연사 (기본) | 빠른 연사, 보통 피해 | 보통 |
| W2 관통탄 | 느린 연사, 높은 피해. 일렬로 늘어선 적을 꿰뚫는다 | 높음 |
| W4 산탄 | 위아래로 살짝 퍼지는 3발. 높이가 다른 적을 동시에 맞힌다 | 높음 |

- **차지 샷**: J를 누르면 일반 탄을 쏘고 충전을 시작한다. 충분히 누른 뒤 떼면 강한 탄을 쏜다. 모든 모듈에 공통이고, 열을 많이 쓴다.
- 모듈 획득 방식: 1차 목표에서는 **처음부터 3종 모두** 쓸 수 있다. 진행하며 하나씩 얻는 방식으로 바꿀 수 있으므로, 사용 가능 모듈 목록을 데이터로 분리해 둔다

### 4.4 페이즈 대시
- 누르면 바라보는 방향(이동 키를 누르고 있으면 그 방향)으로 짧은 거리를 매우 빠르게 이동한다.
- 대시 중에는 **무적**이고 적과 적의 탄을 통과한다. 벽은 통과하지 못한다.
- **연속 3회**: 대시 사이 간격이 짧으면 최대 3번까지 이어서 쓸 수 있다. 3번을 다 쓰거나 연결 시간이 지나면 재사용 대기 시간이 시작되고, 끝나면 3회가 모두 충전된다.
- 땅과 공중 모두 쓸 수 있다. 공중에서는 대시하는 동안 중력을 받지 않는다.
- 초기값 (테스트하며 조정): 거리 1.5타일 (화면 가로 10타일 기준으로 2.5에서 줄임), 시간 0.1초, 연결 시간 0.4초, 재사용 대기 1.2초
- 무적은 피격 무적과 따로 둔 **회피 무적**(`Health.SetEvading`)이라 깜빡이지 않는다. 대시가 끝난 뒤 0.05초까지 유지된다
- 적 통과는 대시 중에만 플레이어 몸에서 Enemy 레이어를 제외하는 방식(`Rigidbody2D.excludeLayers`)이다
- 수치는 `PlayerDashSettings` (`Data/V2/PlayerDashSettings.asset`)

### 4.5 카운터
- 근접형 적은 공격하기 직전에 **신호**를 보낸다. 몸이 빛나고 예비 동작(외계 생물 `bite_1~2`)을 한다.
- 신호가 뜬 뒤 판정 시간 안에 K를 누르면 성공한다. 적이 튕겨나가며 경직된다.
- 실패하면(신호가 없을 때 누르면) 짧은 후딜레이가 생긴다.
- **카운터 처치 (P2)**: 경직된 적을 가까이에서 쏘면 즉사한다. 체력 조각이 떨어지고 열이 크게 내려간다.
- 판정 시간 0.2초, 경직 1.5초, 실패 후딜레이 0.4초 (초기값)

### 4.6 적
외계 생물과 해병 스프라이트를 색과 크기로 변형해 역할을 나눈다. 크기는 픽셀이 깨지지 않도록 **정수배**만 쓴다.

| 적 | 원본 변형 | 행동 | 카운터 |
|---|---|---|---|
| E1 러너 | 외계 생물 (기본) | 플레이어를 향해 달려와 문다 | 가능 |
| E2 브루트 | 외계 생물 2배 크기, 붉은 색조 | 느리고 단단하다. 정면 사격 피해가 줄어든다. 물기에 넉백이 크다 | 가능 (주요 공략법) |
| E3 천장 기생체 | 외계 생물 상하 반전 | 천장을 기어 다니다 플레이어 머리 위로 떨어진다 | 불가 |
| E4 폭발체 | 외계 생물, 발광 색조 | 가까이 오면 잠시 부풀었다가 자폭한다. 사격으로 죽이면 그 자리에서 터져 주변 적까지 피해를 준다 | 불가 |
| E5 감염 병사 | 해병, 녹색 색조 | 멈춰서 수평 사격. 플레이어와 같은 층에 있을 때만 쏜다 | 불가 |

- 사망: 외계 생물 `alien_die_1~5`, 병사 `marine_die_1~5`. 혈흔(`blood_*`)을 바닥과 벽에 남긴다.
- 색 변형: 미리 만든 색 변형 시트를 쓴다 (팔레트 색을 하나씩 바꿈, 2026-10-27 확정). 공격 신호와 피격 깜빡임은 흰 실루엣 시트를 겹쳐 표시한다

### 4.7 환경 요소
| 요소 | 원본 에셋 | 효과 |
|---|---|---|
| X1 가스탱크 | `scifi_4j1a` 등 | 쏘면 폭발해 범위 피해. 플레이어도 맞는다 |
| X2 방화문 | `scifi_4c1a`, `4e1a` + 콘솔 | 콘솔을 쏘면 문이 잠시 닫혀 적이 들어오는 방향 하나를 막는다 |
| X3 파괴 상자 | `32x32/scifi_boxes_*` | 엄폐물. 적의 돌진과 탄을 막고, 체력이 다하면 부서진다 |
| X4 소등 구역 | URP 2D 조명 | 방이 어둡고 총구 화염·착탄 섬광·적의 신호만 빛난다 |

## 5. 방 구조

### 5.1 방 유형
| 유형 | 내용 | 상태 |
|---|---|---|
| **R1 소탕** | 들어오면 문이 잠긴다. 정해진 웨이브를 모두 처치하면 열린다 | **1차 목표의 중심** |
| R2 방어 | 콘솔이 작동하는 동안 지킨다 | 추후 추가 |
| R3 탈출 | 제한 시간 안에 반대편 문까지 간다 | 추후 추가 |
| R4 보스 | 거대 외계 생물(3배 크기) 등 | 추후 추가 |
| 통로 | 전투 없이 다음 방으로 잇는 복도 | 1차 목표 포함 |

### 5.2 소탕 방(R1) 규칙
- 웨이브 구성(적 종류, 수, 출현 위치, 출현 시점)은 방마다 ScriptableObject 데이터로 정한다.
- 적은 방의 **문**과 **화면 밖 가장자리**에서 등장한다.
- 다음 웨이브는 남은 적이 일정 수 이하가 되면 시작한다.
- 마지막 웨이브를 정리하면 문이 열리고 방 평가(6장)를 보여준다.

### 5.3 방 크기와 지형
- 1화면 = 가로 10타일 x 세로 5.625타일. 1화면짜리 방 = **10x6타일** (복도 단면 6행). 세로로 넘치는 0.375타일은 카메라가 살짝 스크롤한다.
- 소탕 방 기준: 가로 2~3화면(20~30타일), 세로 1~2층(6 또는 12타일).
- 층 구성: 바닥, 얇은 발판(OneWay), 계단 지형으로 높이를 나눈다. 수평 사격만 있으므로 **층을 바꾸는 것이 곧 회피**다.
- 높이 기준: 점프 한 번으로 한 층(약 2타일)을 오를 수 있게 한다 (수치는 8장 이동 재조정 때 확정).

## 6. 점수와 평가

| 항목 | 내용 |
|---|---|
| S1 콤보 배수 | 피격 없이 연속으로 처치하면 배수가 오른다. 카운터 처치와 환경 처치(가스탱크, 폭발체 휘말림)는 가산점. 피격되면 배수가 초기화된다 |
| S2 방 평가 | 방을 클리어하면 시간, 피격 수, 최고 콤보로 S~C 등급을 매긴다 |
| S3 구역 간 강화 선택 | **보류** |

## 7. 진행

- 사망: 현재 방 입구에서 다시 시작한다 (방 단위 재도전).
- 저장: 구역과 방 진행, 최고 평가를 JSON으로 저장한다.
- 진행 구조: **선형 캠페인.** 방을 정해진 순서로 지나간다

### 7.1 1구역 구성 (방 6개, 보스 없음)
| 순서 | 방 | 역할 |
|---|---|---|
| 1 | 통로 | 이동, 점프, 발판 내려가기, 대시를 익힌다. 전투 없음 |
| 2 | 소탕 | E1 러너만 나온다. 사격, 과열, 카운터를 배운다 |
| 3 | 소탕 | E5 감염 병사가 추가된다. 층을 바꿔 피하는 법을 배운다. 파괴 상자 엄폐 |
| 4 | 소탕 | E2 브루트가 등장한다. 카운터와 관통탄의 필요성을 느낀다. 가스탱크 |
| 5 | 소탕 (2층 구조) | 지금까지 나온 적을 섞는다. 산탄으로 위아래 층을 함께 노린다 |
| 6 | 소탕 (마지막) | 가장 긴 웨이브. 클리어하면 구역 클리어 화면 |

- 방 배치와 웨이브는 N7에서 확정한다. 확장 요소(E3, E4, X2, X4)를 넣을 방도 그때 정한다

## 8. 기술 사양

- Unity 6000.3.26f1, URP 2D, 새 Input System
- **게임 단위**: 1타일 = 1유닛 = 64px
- **스프라이트**: PPU 64, Filter Mode = Point, 압축 없음, 피벗 = 발 중앙 (캐릭터) / 왼쪽 아래 (타일)
- **카메라**: Pixel Perfect Camera, 기준 해상도 **640x360** (가로 10타일 x 세로 5.625타일). 720p 2배, 1080p 3배, 1440p 4배, 4K 6배로 정수 확대된다. Crop Frame = Windowbox (정수배가 아닌 창에서는 검은 테두리로 보이는 범위를 유지), Grid Snapping = Pixel Snapping. 메뉴 `Tools/Platformer/Setup/Pixel Perfect Camera (Current Scene)`
- **캐릭터 크기 참고**: 해병 키 약 41px(0.64타일), 외계 생물 몸길이 약 110px(1.7타일)
- **이동 수치**: 이전 수치(키 2.25타일 기준)는 쓰지 않는다. 새 수치 SO는 `Assets/_Project/Data/V2/`에 있다. N1 조정값 (2026-10-27): 최고 속도 4.5, 지상 가감속 60, 점프 2.2타일 (최고점 0.45초, 낙하 중력 1.5배), 최대 낙하 12. 대시 1.5타일. 달리기·대시 거리는 사용자 확인 완료, 점프는 "높이 적당·속도 빠름" 피드백으로 체공 시간을 늘림
- **플레이어 충돌체**: 0.3125 x 0.625타일 (20 x 40px)
- **테스트 씬**: `Assets/_Project/Scenes/TestArena.unity`. 메뉴 `Tools/Platformer/Build Test Arena`가 30x12타일 2층 방(바닥 + 얇은 발판 윗면 4·6·8 + 계단)을 만든다
- **레이어**: Ground, OneWay, Player, Enemy, PlayerProjectile, EnemyProjectile, Interactable, Room (유지). 파괴 오브젝트용 레이어 추가는 N4에서 검토한다 (Project Settings 변경이라 승인 필요)
- **소팅 레이어**: Default → Background → Tiles → Props → Characters → Projectiles → FX → UI (뒤일수록 앞에 그려짐). 메뉴 `Tools/Platformer/Setup/Sorting Layers`
- **태그**: Player 외에는 쓰지 않는다. 판별은 컴포넌트와 레이어로 한다
- **밸런스 데이터**: ScriptableObject (`Assets/_Project/Data/`)
- **저장**: JSON 파일 (`Application.persistentDataPath`)

### 8.1 아트 에셋 (marsh-sci-fi)
- 원본: `Docs/ArtSources/marsh-sci-fi/` (Unity 밖에 보관). `Tools/ArtPipeline/convert_marsh.py`가 필요한 파일을 복사·변환해 `Assets/_Project/Art/`에 둔다
- 타일 이름 규칙: `[행][시퀀스][순서][변형]` (원본 `README.jpg` 참고)
  - 1~6행: 복도 단면. 1 천장 기둥, 2 천장 환기구, 3 벽 상단(조명), 4 벽 하단(문·콘솔·탱크), 5 바닥면, 6 기초
  - 걷는 면 = 5행 윗면
  - 7~9행: 어두운 샤프트 배경과 좌우 기둥
  - 시퀀스 = 왼쪽 끝(1) → 가운데 반복(2a/2b…) → 오른쪽 끝(3)
- `transparancies/`: 콘솔, 얇은 발판(OneWay용), 계단 블록, 혈흔
- `32x32/`: 상자(파괴 상자, 엄폐), 테두리
- 변환 결과 (`Assets/_Project/Art/`): `Characters/Marine/`, `Enemies/{Runner,Brute,Exploder,Infected}/`(동작별 가로 시트 + `_White` 실루엣), `Tiles/{Corridor,Shaft,Stair}/`, `Props/`(피벗 아래 중앙), `FX/`
- 시트 칸 크기: 해병·감염 병사 64x64, 외계 생물 계열 128x64
